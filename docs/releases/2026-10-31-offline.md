## Contents

Download of chapters and volumes, per-series queue, pause/resume, storage used
and removal of the local copies only. Completed books can be read without a
connection and remain after reopening. Transfers require the app
to be open; incomplete copies must be completed before offline reading.
Copies are separated per server/account, protected on the device and
excluded from backups. Shared bookmarks require a connection and
an explicit action; the local reading position also works offline.

The build also includes paged or continuous reading, vertical or horizontal,
both horizontal directions, Italian/English interface and bookmarks.

## App Store

At the 20:22 CET check the public version 1.0.0 is still
`WAITING_FOR_REVIEW` with the previous build 2 and `AFTER_APPROVAL` release.
The existing submission was kept. Italian/English descriptions and review
notes for build 7 are prepared, but have not been applied to
that submission. Publishing to TestFlight is not the same as App Store approval.

After an explicit decision on replacing the existing submission and after
the version becomes editable again, the public submission uses the intended workflow:

```sh
gh workflow run tankarr-ios.yml --repo Renzodef/tankarr-reader --ref main \
  -f action=submit -f version=1.0.0 -f build=7
```

The workflow reuses build 7, runs the checks and rejects a version
that is still in review. Do not withdraw a review as a result of a push.
